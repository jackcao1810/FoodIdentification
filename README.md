# 食堂菜品热量识别系统

一个智能的食堂菜品热量识别和营养建议系统，支持拍照识别菜品并估算热量，同时提供个性化的营养建议。

## 功能特性

- 📸 **多种上传方式**：支持拍照、相册选择、拖拽上传
- 🤖 **AI菜品识别**：基于TensorFlow.js的本地菜品识别模型
- 📊 **热量计算**：自动估算菜品热量和营养成分
- 💡 **智能建议**：基于历史数据提供个性化营养建议
- 📈 **数据统计**：记录和分析饮食历史

## 技术栈

### 前端
- React + TypeScript
- Ant Design UI组件库
- React Camera Pro（摄像头功能）

### 后端
- Node.js + Express
- TensorFlow.js（菜品识别）
- SQLite（数据存储）
- Sharp（图片处理）

## 快速开始

```bash
# 安装依赖
npm run install-all

# 启动开发服务器
npm run dev
```

## 核心功能

1. **图片上传与处理**
   - 支持多种上传方式
   - 自动图片压缩和预处理
   - 实时预览功能

2. **菜品识别**
   - 支持50+种常见食堂菜品
   - 置信度评估和人工确认
   - 多菜品同时识别

3. **热量计算**
   - 基于标准食物成分表
   - 智能分量估算
   - 营养成分详细展示

4. **营养建议**
   - 基于历史数据分析
   - 个性化饮食建议
   - 营养均衡提醒
